Política de privacidade

Vigente a partir de 08/11/2026.

Resumo

O Circuit Breaker não tem cadastro, não vende nada e não coleta dados pessoais neste site.

Este site

Este site é estático. Ele não usa cookies, formulários, rastreadores ou anúncios. O serviço de hospedagem pode registrar dados técnicos de acesso (como endereço IP e navegador) para segurança e operação, segundo a política dele.

O sistema no X

O sistema usa a X API para publicar posts na conta @circbreakerbr. Ele pode ler dados públicos do X, como métricas e respostas aos posts do perfil, para medir o desempenho do conteúdo. Ele não lê mensagens diretas, não segue nem bloqueia contas de forma automática e não vende ou compartilha dados do X com terceiros.

Seus direitos (LGPD)

Você pode pedir informações ou a remoção de qualquer dado seu que o projeto tenha guardado. Envie uma mensagem para @circbreakerbr no X.

Mudanças

Se esta política mudar, a data acima muda também.
